# 免费额度部署

核实日期：2026-09-09。当前使用 **Azure for Students** 学生订阅，沿用项目的 Docker Compose 网站模式。原先的 Oracle、DuckDNS 和个人邮箱方案已替换为 Azure 服务器、Azure 网站域名和 Azure Communication Services Email。

| 持久存储 | 64 GB Premium SSD，Docker 命名卷保存用户数据 | 按订阅的磁盘免费额度抵扣；用户简历不放在临时文件系统 |

| HTTPS | Caddy 自动申请及续期证书 | 无证书购买费用 |
| 登录邮件 | Azure Communication Services Email，Azure 托管发件域名 | 域名免费；每封 $0.00025 加 $0.00012/MB，消耗学生赠金；托管域全订阅最多 10 封/小时 |

Azure for Students 提供 100 美元、有效期一年的赠金，学生订阅保持支出上限开启，不升级为按量付费。免费机型时数、存储、网络等分别计量，实际抵扣以 Azure 账单为准。该方案无需现金付款，但并非所有资源无限免费。[学生额度](https://azure.microsoft.com/en-us/free/students/)、[学生订阅条款](https://azure.microsoft.com/en-us/pricing/offers/ms-azr-0170p/)

Azure 托管发件域名自动完成认证，不需要购买邮件域名。10 封/小时的上限适合首轮试用；扩大开放范围前，需要配置自有认证域名或其他邮件服务。[托管域名](https://learn.microsoft.com/en-us/azure/communication-services/quickstarts/email/add-azure-managed-domains)、[邮件限制](https://learn.microsoft.com/en-us/azure/communication-services/concepts/service-limits#email)

## 复现部署

1. 开通自己的 Azure 学生订阅，检查允许部署的区域以及免费机型容量。不同订阅的可用区域和机型可能不同。
2. 创建 Ubuntu 24.04 虚拟机，使用 [azure-cloud-init.yaml](../deploy/azure-cloud-init.yaml) 安装 Docker、Compose、Buildx 并配置 swap。SSH 只允许部署者的来源 IP，网站开放 80/443。
3. 创建 Email Communication Services 与 Azure 托管域名，再创建 Communication Services 并关联该域名。创建用于 SMTP 的 Entra 应用，只在通信资源范围内授予所需角色。
4. 按[网站部署指南](网站部署指南.md)填写私密 `.env.hosted`。SMTP 使用 `smtp.azurecomm.net:587`、`starttls`，用户名为 SMTP Username，密码为该 Entra 应用的 client secret。[SMTP 官方配置](https://learn.microsoft.com/en-us/azure/communication-services/quickstarts/email/send-email-smtp/smtp-authentication)
5. 在服务器构建并启动，核对 HTTPS、真实邮箱验证码、账号隔离、保存简历以及 PDF/Word 导出。

本机与网站使用独立工作区，本机已有简历不随源码打包。AI 模型服务独立于 Azure 基础设施额度；网站由运营者设置模型密钥，普通用户不能读取或修改密钥。

## 运维

- 定期备份 `hosted-data` 数据卷和私密 `.env.hosted`，更新时不使用 `down -v`。
- SMTP 应用凭据设有到期时间，需要在到期前更换。更换后更新 `.env.hosted` 并重新创建应用容器。
- 1 GB 内存机器使用 swap 承担峰值。若同时导出、诊断明显变慢，增加内存或限制并发；较大机型会消耗更多赠金。
- 服务器和邮件服务的具体交付、验证结果见 [Azure 部署记录](Azure部署记录.md)。
