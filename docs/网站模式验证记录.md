## 实际运行验证

在独立的数据目录启动 hosted 后端、生产 standalone 前端和本机 SMTP 测试收件箱，使用合成邮箱与简历验证，未向真实收件人发送邮件。

1. 未登录访问公开介绍页；私有 API 返回 401。
2. 从邮箱表单申请验证码，实际通过 SMTP 收到邮件，验证后创建账户 A。
3. 保存账户 A 的简历；刷新生产页面后记录仍在。
4. 从工作区成功导出 Word 和 PDF；网站设置页只提供账户与服务信息。
5. 退出后回到公开页面，旧简历不再展示。
6. 验证账户 B 后进入空工作区，账户 A 的文档名称和正文均未残留。
7. 本地服务恢复运行，仍无需登录；原有 7 份简历保留。

临时 Webpack 开发副本遇到 jsdom 样式文件路径错误。按实际交付使用的 Turbopack 生产构建启动 standalone 后，打印与 PDF 导出成功。生产依赖目录和打印页追踪文件也已检查。

另用项目安装的 Next.js 代理函数核对 Caddy 转发形式：两名客户端的 IP 均原样传递，Uvicorn 正确区分客户端；不信任非本机来源伪造的转发头。
