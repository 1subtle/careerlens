# 实时岗位与 JD 记忆

2026-09-08。主工作台提供简历、目标 JD、诊断优化和实时岗位四个入口。

## 已接入的数据源

默认来源为[国家大学生就业服务平台](https://www.ncss.cn/student/jobs/index.html)，提供国内多家用人单位的跨行业岗位，主要服务高校毕业生、校招和实习。官网公开 JSON 搜索接口无需密钥，使用 `jobName`、从 1 开始的页码 `offset`、`limit=10`、`sourcesName=0` 和 `recruitType=0`。

- 每次只查询指定页，完整详情最多并发 3 个；查询页缓存 5 分钟、上限 32 页。完整 JD 从官网详情页提取，同时核对岗位 ID 和标题。
- 保留雇主、地区、学历、专业、人民币月薪、发布日期与更新时间。`publishDate` 和 `updateDate` 分别转换为中国时间日期。
- 官网公开计数存在上限，返回 `total_kind="capped"` 与 `has_more`；这不是整个国内招聘市场的岗位总量，空页停止后翻。统计仅使用当前页完整 JD。
- 记住使用有效服务端缓存；缺少完整详情的岗位保留来源链接、排除统计且不能记住。搜索不写入数据库。

官网依据、真实 HTTP 响应和其他国内平台的状态见[国内招聘来源接入记录](国内招聘来源接入记录.md)。

可切换 [Jobicy](https://jobicy.com/jobs-rss-feed) 多公司国际远程招聘平台。官方公开接口 `GET https://jobicy.com/api/v2/remote-jobs` 无需密钥，提供雇主、完整 HTML JD、远程适用地区、原始发布日期和可选薪资。服务端将 HTML 转为纯文本，保留段落并移除脚本及样式。

- 使用 `count=200`、`tag` 和 `geo` 获取一个查询批次。同一关键词和地区缓存一小时，翻页在服务端按每页 10 条切片，不自动轮询。
- 页面中的“本次返回岗位”是本批有效样本数，并非全平台命中总数；技能与薪资统计仅使用当前页完整 JD。
- `pubDate` 保存为 `published_at`，不冒充更新时间。`fetched_at` 是实际抓取该缓存的时间。
- 地区筛选包括全部、中国相关远程机会、美国和欧洲。China 包含 APAC 等跨地区远程机会，每份 JD 展示原始地区限制；它不代表中国大陆本地综合招聘市场。
- 保留 Jobicy 来源与原文链接。已有缓存过期后，用户需重新搜索再记住 JD，避免提交前端正文冒充官方岗位。

可切换到[腾讯招聘官网](https://careers.tencent.com/search.html)公开查询接口，无需登录、Cookie 或 API Key：

- 列表：`GET https://careers.tencent.com/tencentcareer/api/post/Query`，传入 `keyword`、`pageIndex`、`pageSize=10`、`language=zh-cn`、`area=cn`。
- 详情：`GET https://careers.tencent.com/tencentcareer/api/post/ByPostId`，传入字符串 `postId` 和 `language=zh-cn`。

每次只请求指定页，详情最多并发 3 个。列表的 `Responsibility` 是职责概要，完整 JD 还需要详情中的 `Requirement`。缺少完整详情的岗位保留概要和官网链接，不进入统计，也不能直接记住。远程请求有超时上限，失败返回中文提示。

`Data.Count` 是官网命中总数，图表分母是当前页取得完整 JD 后去重的样本数，两者分开展示。`LastUpdateTime` 保存为 `source_updated_at`，未知的发布日期保持 `null`。腾讯该接口没有结构化薪资，薪资缺失不填充为估算值。页面标明获取时刻，按用户查询获取当前官网数据，不自动轮询，不承诺即时推送或按发布时间排序。

腾讯来源只覆盖腾讯自身岗位。BOSS 匿名搜索接口本次返回业务码 37（环境存在异常），没有继续处理挑战或绕过限制；智联公开网页岗位可以匿名读取，但尚未实现其 HTML 适配。前程无忧合作连接需要平台提供 accessToken，猎聘尚未核实到可用的自助搜索 API；这些平台均未标为已接入。

## 本地接口

统一使用 `/api/v1/career/live`：

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| GET | `/jobs?provider=ncss&keyword=&geo=&page=1` | 默认查询国内毕业生就业来源；返回来源、覆盖地区、缓存状态、数量口径、当前页 JD 与统计；不写数据库 |
| POST | `/jobs/{post_id}/remember?provider=ncss&keyword=&geo=` | NCSS 与 Jobicy 从对应查询的有效服务端缓存取完整 JD；腾讯重新读取详情；按来源与外部编号去重，返回本地 JD |
| POST | `/analyze` | 接收最多 10 份完整 JD 和问题；只分析所传样本，复用规则统计和可选 AI 解读 |

实时分析与旧 `/market/*` 接口独立；主工作台不再读取内置岗位的统计。现有测试和历史接口仍保留兼容性。

## JD 记忆

复用现有 SQLite 岗位记录保存用户主动记住的 JD，不增加第二套存储。手动输入保留“记住这份 JD”动作，来源等元数据可选。API 导入保留来源地址、外部 ID、来源名称及来源提供的发布或更新日期。Jobicy 的完整地区限制和原币种薪资也写入 JD 正文，后续编辑与记忆仍可查看。

原有用户材料和诊断不删除。虚构岗位及对应诊断在主工作台隐藏，示例载入入口移除；测试夹具仍可用于隔离验证。“最近使用的 JD”默认折叠，按最近诊断时间或创建时间排序，点选后回填原文及要求。

## 页面组织

- 目标岗位：JD 原文与名称为主表单，公司、来源、要求校对和最近记录折叠。
- 实时岗位：关键词搜索、来源与样本数量、简洁岗位列表；逐条展开完整 JD。
- 市场统计与建议：默认折叠；图表仅在展开时载入。

主工作台采用桌面工具布局。左侧为功能导航和简历文档列表，主区域保留紧凑工具栏与单独滚动的编辑内容。正文以连续章节呈现，目录可直接跳转；技能、荣誉和经历等长文本随内容增高。导入为独立操作视图，预览与编辑在同一工作区切换，不在文档底部追加第二份内容。保存使用 ⌘S / Ctrl+S 或工具栏按钮，同一文档保存后保持编辑器挂载和滚动位置。

AI 默认开启，侧栏开关可手动关闭，在工作区切换页面时保持当前选择。未配置模型时显示设置入口。保留岗位来源、时间、地区字段和真实请求异常，移除重复范围解释。

视觉采用奶油色背景、暖白纸面、深紫轮廓、黄色选中态和绿色 AI 开关。品牌图标用于导航，插画缩小为页头点缀；正文保留连续编辑、紧凑工具栏和自动增高的文本框。原有图像资产见 [插画资产说明](CareerLens-插画资产.md)。

工作流程参考 [Resume Matcher](https://github.com/srbhr/Resume-Matcher) 的导入、匹配和导出步骤，以及 [Reactive Resume](https://github.com/amruthpillai/reactive-resume/blob/main/DESIGN.md) 的内容优先与分组编辑原则。应用界面样式与导出简历排版分别维护。
