最终复现应在独立目录解压并依次检查：安装依赖、初始化空库、启动、创建合成简历和JD、规则与AI流程、独立采纳、PDF/Word导出、重启持久化。网站另查账号隔离及真实邮件/HTTPS。记录包名、哈希、代码状态、环境、检查人和时间。

## 3. 视频检查

成片目标为9分30秒，保留转场余量；具体分镜见[成果演示脚本](成果演示脚本.md)。

表3-1 视频技术与内容要求

| 项目 | 要求 |
| --- | --- |
| 文件与编码 | MP4容器，H.264视频，AAC音频 |
| 分辨率 | 1920×1080或1280×720 |
| 时长 | 严格少于10分钟 |
| 大小 | 建议不超过500MB |
| 内容 | 背景、架构、核心操作、技术亮点、实现思路五部分 |
| AI展示 | 演示项目中的AI诊断/改写，并说明AI辅助开发实例 |
| T5对照 | 针对同一JD展示原版和定向版，解释事实和修改逻辑 |
| 视听 | 画面完整、文字可读、声音清楚、字幕/标注不遮挡操作 |

指导书第6.1.3.3节出现“组别_项目名称_成果讲解视频.mp4”，第6.1.4.1节和目录树使用“组长姓名组-选题名称.mp4”。本项目按后面的统一提交规范准备最终文件名；若学委另有通知，提交时统一调整，不需要生成两份内容相同的视频。
