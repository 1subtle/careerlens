# CareerLens 竞品体验与样本差距分析

> 版本：v1.0｜编制日期：2026-09-09｜课程对应：T5 至少 2 款招聘 APP 实际体验、5 份真实 JD 与 3 份学生简历对照。本文为可直接执行的采集、编码和归档文档，附公开合成算例；未填写的记录均表示待采集。

## 1. 研究问题与已有材料

本项工作检验三个问题：招聘 APP 能否帮助学生理解匹配依据并控制简历修改；学生材料中有哪些表达差距、技能差距和待确认信息；CareerLens 的证据对照与定向改写能否改善同一份材料的表达。公开资料比较沿用[调研报告](调研报告.md)的 2026-09-08 记录，本轮未重新访问外部页面。

## 4. 访谈与任务观察提纲

访谈以一次具体准备经历为起点，建议每位参与者约 20—30 分钟。以下为研究安排，尚无访谈发生记录。

表 8 半结构化访谈提纲

| 阶段 | 提问或操作 | 追问与观察 | 记录字段 |
| --- | --- | --- | --- |
| 背景 | 最近一次针对某岗位准备简历，最先做了什么 | 用了哪些工具，在哪一步返工 | 时间、工具、步骤 |
| 岗位理解 | 请指出这份 JD 的三项主要要求 | 依据在何处，哪些是普通要求或优先项 | 引文、优先级、理解困难 |
| 经历核对 | 哪一段经历能支持这些要求 | 若没写清，是否确实做过，能提供什么材料 | 原文、本人补充事实、可核查依据 |
| 分数解释 | 看完系统结果后，请说明分数衡量什么 | “待确认”与“未掌握”是否不同 | 原话摘要、正确/误解及理由 |
| 建议审阅 | 请决定接受或拒绝一段改写 | 哪句更具体，哪句可能夸大，为什么 | 逐句判断、引用与决策 |
| 版本和导出 | 找到原稿与目标版并导出 | 能否确定正在使用哪个版本 | 成功、耗时、求助点 |
| 改进建议 | 整个过程中最影响继续操作的环节是什么 | 如果只改一个地方，应改哪里 | 问题位置和原因 |

观察表分别记录独立完成、提示后完成、主持人代操作和未完成；不得把代操作计为独立完成。可征得同意后录屏，报告只使用脱敏片段。
