# Level 2 / Level 3 交付与验收

2026-09-10。已发布至 [CareerLens](https://careerlens.cc)。本轮完成课程 T5 的 Level 2 / Level 3 技术缺口，现有账号、积分和用户数据保留。

## 直接使用

| 功能 | 入口与操作 |
| --- | --- |
| STAR 经历优化 | “诊断与优化” → 选择已保存简历、目标 JD → 分析匹配 → 选择一段经历 → “生成 STAR 定向建议” |
| 四项依据与补充 | 查看情境、任务、行动、结果；已有内容显示来源短引文，缺项显示具体问题。报告、清单等实际交付物可以作为结果 |
| JD 关键词与量化建议 | 同一结果中查看岗位原词的表达建议、可确认的数量/规模/过程/交付问题；“补充这些信息”返回输入区，再生成建议 |
| 采纳和对照 | 对照原文与建议稿，采纳后生成独立定向版本；保留原文、历史建议及同岗复评入口 |
| 已录入 JD 聚合 | “实时岗位” → “已保存岗位分析” → 选择类别、城市和日期 → “更新岗位统计” |
| 近期热门技能 | 支持近 30 天、近 90 天、全部时间和自选起始日期；词云按筛选后去重岗位统计，每个岗位的同一技能只计一次 |
| 薪资与技能分布 | 使用同一份样本绘制薪资散点图和类别技能热力图，支持币种/周期选择；明细和历史可回看 |
| AI 职业准备建议 | “AI 解读当前样本”根据已经提交的统计范围给出学习、项目和求职下一步；修改筛选后须更新统计再解读 |

首次使用需要先保存自己的简历和至少一个完整 JD。实时招聘可直接检索 NCSS、腾讯、Jobicy；另外五个平台保留官网搜索入口，取得 JD 后可在“目标岗位”粘贴保存。

## 实现依据与统计口径

先完成 GitHub 检索、固定提交、实际源码和许可证核对，再实施。Resume-Matcher 的改写策略在运行时直接导入；resumePolice 的 STAR、追问和衡量方式适配到单段优化。岗位市场项目用于参考先筛选后统计、岗位去重、技能分母、日期及薪资覆盖等方法。具体来源、许可与适配范围见[开源参考记录](Level23开源参考记录.md)。

新字段兼容旧草稿和历史。STAR 每项已有证据须关联有效来源，缺项以问题表达；关键词与量化建议不会自动作为新经历写入正文。采用原有生成及至多一次结构纠错流程。市场建议取消隐式的模型筛选调用，一次请求解读页面已经确定的样本；空样本不调用模型。

日期筛选仅使用岗位发布日期，缺失日期不以采集时间或来源更新时间代替；页面显示未知日期与排除数。三类图表使用同一份去重样本，技能比例以类别内岗位数为分母。不同计薪周期并列显示原始区间，未知工时、工作天数和缺失薪资不估算。未提供类别的实时来源按清楚的标题词归类，保留上游类别及用户已经校对的类别，无法判断的标题留为“其他”。

## 本轮验证

- 前端整套测试：75 个文件、637 项通过；TypeScript 和 ESLint 通过。最后移除重复理由展示后，诊断相关 10 项再次通过。
- 后端：117 项相关回归通过；最后复核诊断/API 37 项，其中 22 项为新增覆盖，合计覆盖 139 项不同测试。包含 STAR 结构、旧历史兼容、日期边界、去重、三源分类、用户隔离、退款及积分不足。
- 真实模型：共 11 次有界请求，全部使用隔离临时账号、数据库及合成材料。覆盖平淡经历、补充事实、不相关 JD、已经清楚的经历、跨城市问题和两周学习路线。根据实测修正了“报告被误列为没有结果”和“擅自将日薪折成月薪”的提示词问题，最终复测通过。
- 上线后闭环：使用正式镜像实际代码，完成保存简历和 JD、诊断、真实 AI STAR 改写、历史回看、采纳独立版本、重复采纳幂等、已保存岗位统计；保留原始简历，两份版本，1 次模型请求，测试账户积分 20 → 19、预留积分 0。
- 浏览器：本地隔离合成数据验证桌面及 390px 手机布局、三类图表、筛选后禁用旧范围 AI、历史入口和 STAR 补充交互；手机页面无横向溢出。浏览器界面验收与真实模型调用分开留证。
- 公网：20 项检查通过，含首页、登录、个人中心各路由、健康检查及未登录私有接口保护。正式站点浏览器加载超时，线上可用性结论依据 HTTP 检查、镜像校验及上述正式代码闭环。
- 发布：验证固定基线、完整前端构建产物和 8 个后端文件；源文件同步前创建备份。7 种激活/回滚模拟场景及源码同步验证通过。上线前后只读数据库审查完全一致，均通过。
- 交付清单：`data/schema.sql` 已重新生成，与当前 ORM 的 11 张业务表及列一致，重复初始化通过；`requirements.txt` 已同步全部直接依赖，推荐复现方式仍为 `uv sync --frozen`。

真实模型样例属于功能与质量检查，不能代表所有简历的效果；生成稿仍提供原文、来源与采纳审阅。
