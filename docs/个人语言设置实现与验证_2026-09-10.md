# 个人语言设置实现与验证

日期：2026-09-10

网页语言已接入个人账户设置。在线模式从当前用户的 `/account/profile` 读取和保存偏好，网页会随设置切换中英文；简历原文、招聘信息及已保存的分析内容保持原语言。

## 实现范围

- `LanguageProvider` 位于根布局的 `AuthProvider` 内，统一覆盖公开首页、登录页、工作区和个人中心。文档根元素的 `lang` 同步更新，辅助技术可以识别当前语言。
- 在线账户不再请求全局 `/config/language`。个人设置通过 `/account/profile` 的 GET/PATCH 读取和保存，保存失败不会显示为成功。
- 账户切换时立即隐藏上一账户的偏好，丢弃已过期的读取与保存响应。跨标签页通过账户 ID 和变更标记通知刷新，各标签页重新读取当前会话所属账户；通知不包含个人资料。
- 未登录的首页和登录页提供中文／English 切换，使用独立的公开页面缓存。本地部署仍保留原有七种语言配置和缓存。
- CareerLens 的导航、简历编辑工具、排版、目标岗位、诊断、改写、实时岗位、图表和历史记录操作使用显式中英文文案。文案在 React 组件中选择，没有使用 DOM 文本替换。
- 工作区“个人中心”入口指向 `/account/wallet`，保留未保存编辑的离开确认。
- 历史分析时间采用个人时区。浏览器不支持某个服务端时区名称时，回退至 `Asia/Shanghai`，保证历史记录仍能显示。

## 自动化验证

新增 14 项测试，覆盖：

1. 在线账户加载偏好后，公开页面文案和 HTML 语言同步变化，并且不访问全局配置接口。
2. 旧账户的延迟读取、延迟保存不会覆盖新账户；其他账户的跨标签事件不会刷新当前偏好。
3. 保存失败保留原设置，加载失败提供错误状态并可重试。
4. 本地七语言行为和未登录偏好缓存相互独立。
5. 简历、岗位、诊断、实时岗位与历史控件显示英文；切换语言保留用户输入、已保存岗位标题和未保存编辑。
6. 历史时间遵循个人时区，并覆盖 `Factory` 等浏览器不支持的时区。

新增测试与原有 CareerLens 测试共 59 项通过。定向 ESLint 和 TypeScript 检查通过。全量前后端测试与正式部署由主任务汇总。

## 可视验收环境与边界

本轮隔离预览地址为 `http://127.0.0.1:3103/account/settings`，使用 `127.0.0.1:8113` 的合成 API。账号和账单均为虚构样本，语言修改只保存在测试服务内存中，不发送验证码、不支付、不操作正式用户数据。

预览项目副本位于 `/private/tmp/careerlens-ui-preview`，服务脚本位于 `/private/tmp/careerlens-ui-mock.py`。该环境用于个人中心六个栏目、桌面与手机布局、语言切换和重载的可视验收，不能代替正式后端的账户隔离、账务或数据库测试。浏览器可视结果与截图由主任务另行汇总。
