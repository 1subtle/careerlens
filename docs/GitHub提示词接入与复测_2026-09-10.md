# GitHub 提示词接入与复测

2026-09-10。主流程的“润色经历”现已复用 Resume-Matcher 的原始策略常量，并将其定向优化核心模板适配为中文单段输出。此前底层架构已经复用，但该入口使用 CareerLens 自写提示词；上游完整简历优化模板仅由旧接口调用。

## 来源与实际复用

固定源为 [srbhr/Resume-Matcher@0932418cf694de227fd5ca030ddbc0d1f40b1bef](https://github.com/srbhr/Resume-Matcher/tree/0932418cf694de227fd5ca030ddbc0d1f40b1bef)，许可为 [Apache-2.0](https://github.com/srbhr/Resume-Matcher/blob/0932418cf694de227fd5ca030ddbc0d1f40b1bef/LICENSE)。上游许可保留在 `app/LICENSE`。本次核查将官方固定版本与导入基线、当前本地模板逐字比较。

| 内容 | 主流程中的处理 |
| --- | --- |
| FastAPI、Next.js、LiteLLM、简历及修改记录 | 继续沿用既有上游架构 |
| [DIFF_STRATEGY_INSTRUCTIONS](https://github.com/srbhr/Resume-Matcher/blob/0932418cf694de227fd5ca030ddbc0d1f40b1bef/apps/backend/app/prompts/templates.py#L486) | 运行时直接 import 原常量；有 JD 或结构化岗位要求时用 keywords，否则用 nudge |
| [DIFF_IMPROVE_PROMPT](https://github.com/srbhr/Resume-Matcher/blob/0932418cf694de227fd5ca030ddbc0d1f40b1bef/apps/backend/app/prompts/templates.py#L527) | 将局部定向改写、已有表达保留、岗位术语等义重述、实际职责与成果保留等规则适配为中文 |
| 上游输出 targeted changes 的设计 | 收窄到用户选定的一段，生成建议稿，预览后采纳为独立版本 |
| CareerLens 输出协议 | 保留 draft、claims、missing_facts、reason，以及来源位置校验与结构反馈重试 |

新模板位于 `app/apps/backend/app/prompts/career_rewrite.py`，顶部记录固定提交、源文件、许可及适配内容。未修改原始 `templates.py`。此实现是共享策略加核心模板适配，不是逐字使用整份上游提示词，也没有导入上游整份简历的技能规划、路径变更和可选二次生成。

原始上游没有显式 STAR 指令，本次也未将 STAR 宣称为上游复用内容。Reactive Resume 和 OpenResume 的既有参考范围仍为编辑器/导入体验，本轮未声称复制它们的运行时 AI 提示词。

实际入口：前端 `careerApi.rewrite` → `POST /api/v1/career/rewrites` → `career_ai.rewrite` → `build_rewrite_prompt` → 原 `ask_json` / LiteLLM → 同一输出校验 → 保存待采纳草稿。没有新增独立模型审稿阶段或额外计费调用。

## 新旧对照

使用线上配置的 `deepseek-v4-flash`，在独立 Python 进程和临时数据库中测试同一组四个合成案例。旧版、第一轮适配版、最终版各生成 4 次，共 12 次供应商请求；最终版均一次生成成功，耗时 1.45–1.85 秒。测试不读取真实简历，临时账号积分与线上账号分离。

| 样例 | 旧提示词 | 最终模板 |
| --- | --- | --- |
| 泛泛的校园活动经历 | 添加原文没有的 Excel、独立写报告及用途 | “在校园活动中，协助整理用户反馈，并完成活动报告。”保留协助程度，没有新增工具、指标和影响 |
| 提供补充事实 | 加入 5 人、三个环节，但有重复概括及无依据用途 | 将 5 名报名者、报名/签到/场地、问题清单和协助报告合为具体经历，正确关联 fact 来源 |
| 不相关的嵌入式 JD | 正文保留原文，补充问题偏向嵌入式技术 | 保留原文，说明无直接对应，问题围绕该段实际经历 |
| 原文已经清楚 | 正文保留，给出 4 项补充建议 | 保留原文并标记 unchanged，说明保留原因，最多 3 项可选补充问题 |

第一轮适配已消除 Excel 和“独立撰写”，但仍将普通报告写成“需求说明文档”，并假设其用于活动优化。因此进一步明确：岗位术语只作等义表达，责任程度、产物名称和用途按原义保留；随后重新测试四例，获得上表最终结果。

原始记录：[旧版](evidence/rewrite-upstream-baseline-2026-09-10.jsonl)、[第一轮适配](evidence/rewrite-upstream-current-2026-09-10.jsonl)、[最终版](evidence/rewrite-upstream-final-2026-09-10.jsonl)。复测脚本：`scripts/probe_ai_rewrite.py`，支持 `--baseline`、`--case` 与 `--dry-run`，每次运行限制 6 次完整生成和 8 次供应商尝试。

日志中的 `passed` 表示调用与结构校验成功；上表的内容质量判断来自逐项对照原始材料。来源 ID 有效不等于事实经过独立证明，四例合成测试也不是普遍质量保证。
