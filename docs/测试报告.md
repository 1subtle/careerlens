### 2.3 可复现命令

先按[系统运行说明](系统运行说明.md)安装锁定依赖。以下命令与本轮相同的测试选择一致；本轮直接调用已安装环境的 Python 与 Node，未执行依赖重装。

```bash
cd app/apps/backend
uv run --frozen --extra dev pytest \
  tests/unit/test_career_matching.py \
  tests/integration/test_career_api.py \
  tests/integration/test_career_diagnosis.py \
  tests/integration/test_hosted_auth.py \
  tests/integration/test_tenant_isolation.py \
  tests/integration/test_ncss_api.py \
  tests/integration/test_jobicy_api.py \
  tests/integration/test_recruitment_api.py \
  tests/integration/test_resume_docx.py -q
```

```bash
cd app/apps/frontend
npm test -- \
  tests/auth-flow.test.tsx \
  tests/career-diagnosis.test.tsx \
  tests/career-enhancements.test.tsx \
  tests/career-live-jobs.test.tsx \
  tests/career-resume-panel.test.tsx \
  tests/career-resume-document.test.tsx \
  tests/career-resume-sections.test.tsx \
  tests/career-resume-dialogs.test.tsx \
  tests/career-workspace.test.tsx \
  tests/career-layout.test.ts \
  tests/print-session.test.ts \
  tests/resume-photo.test.tsx \
  tests/settings-workflow.test.tsx
```
