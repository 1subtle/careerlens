# 个人中心升级

日期：2026-09-10。

CareerLens 个人中心采用独立侧栏，将充值从原有设置长页中移入钱包管理。页面沿用网站标识，以白色卡片、浅灰背景和蓝色选中状态组织账户功能。信息结构参考用户提供的 PackyAPI 截图，并结合 [Notion 账户设置](https://www.notion.com/en-gb/help/account-settings)和 [GitHub 账户设置](https://docs.github.com/en/account-and-profile/how-tos/account-settings)中的资料、语言、安全及数据管理功能。

## 页面与功能

| 栏目 | 路径 | 已实现功能 |
| --- | --- | --- |
| 钱包管理 | `/account/wallet` | 可用积分、处理中预留、累计消费、累计充值；真实充值开关与套餐；订单支付详情 |
| 充值账单 | `/account/orders` | 金额、积分、订单号、时间、状态；状态和日期筛选；订单搜索；继续加载 |
| 消费日志 | `/account/usage` | 每次消费、预留、退回、赠送和充值记录；类型和日期筛选；继续加载；CSV 导出 |
| 个人设置 | `/account/settings` | 昵称、只读登录邮箱、复制账号 ID、中文／English 网页语言、时区、保存与取消 |
| 账号安全 | `/account/security` | 邮箱验证码登录说明、当前及其他会话、逐个退出或退出其他所有会话 |
| 数据管理 | `/account/data` | 下载当前账户的 JSON 数据包，前往工作区管理记录 |

`/account` 默认进入钱包，旧 `/settings` 在线模式进入个人设置。本地部署继续使用本地模型与语言设置页。移动端侧栏转换为可展开导航。

网站目前采用邮箱验证码登录，邮箱作为登录标识只读。网页语言真实覆盖公开页、登录页、个人中心和 CareerLens 工作区；用户简历、JD 及已保存的 AI 结果保留原语言。语言与时区按账号保存，刷新、重新登录或更换设备后从服务器读取。详细实现见[个人语言设置实现与验证](个人语言设置实现与验证_2026-09-10.md)。

## 数据与交互保证

- 账户偏好新增认证库第 3 版迁移，原认证库第 1、2 版及业务库迁移保持不变。旧账户自动补齐默认偏好；旧会话继续有效，新会话增加不含令牌的公开 ID、创建时间和简化设备说明。
- 账户与账单接口从已验证会话获取用户身份。请求中不能修改账号 ID 或邮箱，用户不能撤销其他账号会话；当前会话通过正常退出流程结束。
- 个人数据导出读取当前用户独立业务库中的显式数据表，不导出 API 密钥、认证令牌或内部处理令牌。积分账务在充值账单和消费日志中查看，消费日志可单独导出 CSV。
- 设置保存失败保留草稿，保存成功后才应用语言。其他标签页刷新偏好时同步干净表单；存在本地修改时只提交修改过的字段，避免覆盖其他字段的新设置。离开和退出时提示未保存修改。
- 账单筛选在服务端执行，日期以所选时区解释，分页使用稳定游标。消费日志 CSV 导出全部匹配记录，最多 10,000 条；超过时明确要求缩小日期范围。CSV 时间标为 UTC。
- 浏览器不支持的时区回退上海时区，避免账单及历史页面报错。跨账号切换会丢弃过期请求结果。
