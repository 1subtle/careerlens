# 国内招聘来源接入记录

2026-09-08。本轮仅使用匿名公开请求和合成测试材料；没有使用登录 Cookie、绕过验证码或写入个人数据库。

## 已接入：国家大学生就业服务平台

[国家大学生就业服务平台](https://www.ncss.cn/)由教育部主管、教育部学生服务与素质发展中心运营。其岗位来自国内多家用人单位，覆盖多个行业，主要服务高校毕业生、校招和实习。它的覆盖范围不能等同于全国社会招聘市场。

官网[职位搜索页](https://www.ncss.cn/student/jobs/index.html)加载的[搜索脚本](https://t1.chei.com.cn/ncss/student/js/jobindex-1.0.21.js)直接使用公开接口：

```text
GET https://www.ncss.cn/student/jobs/jobslist/ajax/
    ?jobName=数据分析&offset=1&limit=10&sourcesName=0&recruitType=0
```

- `sourcesName=0` 请求平台自有发布的岗位，避免将第三方合作平台的摘要当成完整 JD。`recruitType=0` 选择职位，排除泛招聘公告。
- `offset` 是从 1 开始的页码，`limit=10`。这一语义同时由官网[分页脚本](https://t2.chei.com.cn/ncss/student/js/set-page-new-1.0.3.js)和实际第 1、2 页请求验证。
- 列表返回公司、岗位名称、省市、学历、专业、月薪上下界及 `publishDate` / `updateDate` 毫秒时间戳。月薪字段单位为千元，转换为人民币 `k/月`；日期按中国时间分别写入发布和更新时间。
- 完整 JD 在 `https://www.ncss.cn/student/jobs/{jobId}/detail.html` 的 `mainContent` 中。解析时同时核对页面岗位编号和标题，移除脚本、样式和页面导航。
- 页面和接口均不需要 API Key。该接口是官网网页使用的公开接口，未发现承诺版本稳定性或第三方服务 SLA 的开放平台文档。

实际调用新 provider，以“数据分析”查询第 1 页取得 10 个岗位、10 家不同企业、10 份完整 JD；第 2 页返回不同岗位。首份[客服数据分析专员](https://www.ncss.cn/student/jobs/41wZcB2u4XtaJUC65YAv7A/detail.html)完整正文及结构字段为 311 字符，发布日期为 2026-09-01、更新日期为 2026-09-02。搜索及这次联调均未持久化岗位。

### 数量与分页口径

本次测试中，空查询、“Python”和“数据分析”的 `pagenation.count` 均为 100；“Python”的第 2 页一度返回空列表，因此不能把这个数字视为全站真实命中总量。后端保留原始计数，同时返回 `total_kind="capped"`，界面用公开检索口径展示。`has_more` 只有在当前页返回满 10 条且尚未达到公开计数时才为真；空页会停止后翻。

不自动遍历后页。每个请求最多读取 1 页及 10 份详情，详情并发上限为 3。查询页缓存 5 分钟，最多保留 32 页；过期缓存清理后才能继续添加。缓存命中保留原始 `fetched_at`。

### 应用接口

```text
GET  /api/v1/career/live/jobs?provider=ncss&keyword=数据分析&page=1
POST /api/v1/career/live/jobs/{jobId}/remember?provider=ncss&keyword=数据分析
```

搜索和记住接口默认来源均为 `ncss`。来源 ID 支持字母和数字；腾讯与 Jobicy 保持各自数字 ID 校验。地区接受空值、`all` 或 `china`。

记住只接受该关键词下仍有效的服务端完整 JD 缓存，不接收客户端传入的“官方正文”。详情失败的岗位保留列表信息和来源链接，排除统计，并禁止直接记住。记住复用现有来源名与外部 ID 去重逻辑，已经保存和编辑过的内容不会被重新查询覆盖。搜索不写数据库；统计仅分析当前页完整样本。

## 验证

新增 NCSS 测试覆盖默认国内来源、真实分页参数、完整详情与身份核对、HTML 清洗、发布时间时区、薪资、搜索不落库、缺详情不能统计或记住、重复记忆保留用户编辑、缓存过期和容量限制、来源错误、非法 ID 和地区。

`test_ncss_api.py`、`test_recruitment_api.py` 和 `test_jobicy_api.py` 共 29 项通过；测试使用 MockTransport 和隔离临时数据库。新 provider 的真实匿名查询已验证 10 份完整 JD，无 API 凭据或个人材料参与。
