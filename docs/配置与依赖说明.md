## 配置位置与优先级

- 后端：复制 `app/apps/backend/.env.example` 为同目录 `.env`。进程环境变量优先于 `.env`，最后使用代码默认值。
- 前端：复制 `app/apps/frontend/.env.example` 为同目录 `.env.local`。`NEXT_PUBLIC_` 变量在构建时进入浏览器包，修改后需重建生产前端。
- 网站：复制根 `.env.hosted.example` 为 `.env.hosted`，通过 `docker compose --env-file .env.hosted -f compose.hosted.yaml ...` 使用。
- 本地模型设置：页面保存的提供商、模型及对应加密密钥优先于环境默认配置。改用 `.env` 后仍使用旧模型时，先检查页面已保存的设置。

## 后端常用参数

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| `CAREERLENS_MODE` | `local` | `local` 无登录，`hosted` 启用账号隔离 |
| `DATA_DIR` | 后端目录下 `data` | 数据库、设置、加密密钥与模型缓存 |
| `LLM_PROVIDER` | `openai` | 模型提供商 |
| `LLM_MODEL` | `gpt-5-nano-2025-08-07` | 提供商实际支持的模型标识 |
| `LLM_API_KEY` | 空 | 模型凭据，本地模型可按服务要求留空 |
| `LLM_API_BASE` | 未设置 | 自定义接口地址 |
| `FRONTEND_BASE_URL` | `http://localhost:3000` | 后端访问打印页面的地址 |
| `REQUEST_TIMEOUT_SECONDS` | `240` | 长请求上限，范围 30–1800 秒 |
| `PDF_MAX_CONCURRENCY` | 代码默认 `4`，网站配置 `1` | 同时生成 PDF 的最大数量 |
| `CORS_ORIGINS` | 本机 3000 地址列表 | JSON 数组，允许的前端来源 |
| `LOG_LEVEL` / `LOG_LLM` | `INFO` / `WARNING` | 应用与模型日志级别 |

`HOST`、`PORT`、`RELOAD` 控制 `uv run app` 启动入口；直接执行 `uvicorn` 时以命令行参数为准。

模型提供商包括 `openai`、`openai_compatible`、`azure_foundry`、`anthropic`、`openrouter`、`gemini`、`deepseek`、`groq` 和 `ollama`。兼容 OpenAI Chat Completions 的自建服务使用 `openai_compatible`，Base URL 按服务填写；Docker 内访问宿主机服务时使用容器可访问的主机地址。

## 前端常用参数

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| `BACKEND_ORIGIN` | `http://127.0.0.1:8000` | Next.js 代理的后端地址 |
| `NEXT_PUBLIC_API_URL` | `/` | 浏览器请求基址，默认同源 |
| `NEXT_PUBLIC_REQUEST_TIMEOUT_MS` | `240000` | 浏览器与代理超时，范围 30000–1800000 毫秒 |

前后端超时应对应，例如后端 240 秒、前端 240000 毫秒。生产构建前设置 `BACKEND_ORIGIN`；改变代理目标后重新构建。标准 Docker 镜像内部固定前后端端口，无需调整这些地址。

## 语义模型与浏览器

本地语义检索使用 `Xenova/multilingual-e5-small`，固定修订 `761b726dd34fb83930e26aab4e9ac3899aa1fa78`。下载器校验 ONNX 模型与 tokenizer 的 SHA-256，下载文件约 135 MB。准备命令：

```bash
cd app/apps/backend
uv run --frozen python -m app.scripts.prepare_embeddings
uv run --frozen python -m playwright install chromium
```

Docker 同时准备中文字体和浏览器系统库；源码方式在 Linux 上按[运行指南](系统运行说明.md)补齐。首次安装需要联网，压缩包不包含模型权重、Chromium 和已安装依赖。

网站认证、邮件、积分和支付参数见[网站部署指南](网站部署指南.md)及根 `.env.hosted.example`。
