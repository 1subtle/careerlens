# 验证说明

先按[运行指南](系统运行说明.md)完成依赖安装。以下测试默认不访问真实模型；实时岗位和真实 AI 服务另按功能流程验证。

## 后端测试

```bash
cd app/apps/backend
uv run --frozen pytest
```

覆盖规则解析、匹配、改写与版本、数据库迁移、接口、账号隔离、积分和支付等逻辑。默认排除 `eval` 标记的真实模型评价；跳过项以 pytest 输出说明为准。

## 前端检查与生产构建

```bash
cd app/apps/frontend
npm ci --no-audit --no-fund
npm run test
npm run lint
npm run build
npm run typecheck
```

生产构建会进行 TypeScript 检查并生成路由类型，随后可单独复核 `typecheck`。首次构建需要访问字体下载服务。成功后可在同目录运行 `npm run start -- --hostname 127.0.0.1 --port 3000`，后端仍需保持运行。

容器生产构建和启动：

```bash
docker compose up --build -d
docker compose ps
curl -f http://127.0.0.1:3000/api/v1/health
```

## HTTP 功能验证

在本地模式启动前后端后，从根目录执行：

```bash
python3 scripts/smoke.py
# 容器模式
python3 scripts/smoke.py --base-url http://127.0.0.1:3000
```

脚本使用虚构示例创建临时简历与 JD，验证解析、规则匹配、改写采纳、重复采纳、原始快照及短简历和多页 PDF 导出。测试结束后删除本次创建的数据，输出 `.local/qa/smoke-result.json` 与两份 PDF。规则分数对应固定测试材料，不表示真实求职成功率。

浏览器验证模板、字体、上方工具栏整体折叠、Word 下载、AI 生成与招聘搜索，按[功能验证表](系统运行说明.md#功能验证流程)操作。网站登录与账户隔离按[部署检查](网站部署指南.md#启动与检查)操作。

## 源码包生成与复核

先提交所有源文件修改，再执行：

```bash
python3 scripts/package_source.py
```

脚本只打包当前 Git 提交，要求工作区无未提交或未跟踪文件；生成 `dist/CareerLens-source-<提交短号>.zip`、对应 `.sha256`，并在包内附加 `SOURCE-MANIFEST.json`。它同时检查 ZIP CRC、必需入口文件和每个文件的 SHA-256。

验证收到的压缩包：

```bash
# 在 ZIP 和 .sha256 所在目录执行
shasum -a 256 -c CareerLens-source-<提交短号>.zip.sha256
unzip CareerLens-source-<提交短号>.zip
cd CareerLens
python3 scripts/package_source.py --verify .
```

将命令中的占位文件名替换为实际文件名。解压目录不含 `.git`，可以直接安装、构建和运行；重新生成提交型交付包需使用 Git 仓库。逐文件校验请在安装和运行前执行，以便区分交付原件与后续产生的缓存、配置和数据。

源码包验证完成后，在该解压目录重新执行安装、测试、构建和 HTTP 验证，即可检查交付内容是否独立完整。安装结果不依赖原工作区的 `.env`、数据库或本地缓存。
